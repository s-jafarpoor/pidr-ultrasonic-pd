# Physics-informed domain randomization for ultrasonic partial discharge classification

This repository contains the code for training and evaluating classifiers of airborne ultrasonic partial discharge signals under realistic field conditions. A physics-based simulator places laboratory waveforms into randomized field conditions (distance with air absorption, reverberation, loss of the trigger, sensor response and industrial noise), and the models are tested on a set of stress conditions with a leakage-safe cross-validation protocol.

## Data

The code uses the public dataset "Acoustic waveforms generated by several types of partial discharges in laboratory environment". The dataset is not included in this repository. Download it and place the four CSV files in the same folder as the scripts:

```
PD_in_Air_12kV.csv
PD_in_Void_25kV.csv
Corona_11kV.csv
Noise_NoPD.csv
```

## Installation

Python 3.9 or newer is required.

```
pip install -r requirements.txt
```

A GPU is used automatically if available, but everything also runs on a CPU.

## Files

| File | Purpose |
|---|---|
| `pd_common.py` | Shared code: data loading, cross-validation splits, field simulator, models and metrics |
| `01_audit.py` | Data audit and shortcut analysis |
| `02_run_experiments.py` | Main experiments and ablation study |
| `03_statistics.py` | Statistical analysis of the main experiments |
| `04_multiwindow.py` | Decisions fused over several consecutive windows |
| `05_extended.py` | Simulator checks, comparison of model families, detection at a fixed false-alarm rate, hyper-parameter sensitivity and perturbation analysis |
| `make_figures.py` | Figures from the saved results |

## Usage

Run the scripts in this order:

```
python 01_audit.py
python 02_run_experiments.py
python 03_statistics.py
python 04_multiwindow.py
python 05_extended.py
python make_figures.py
```

Scripts 02, 04 and 05 accept `--quick` for a short test run. Long runs can be interrupted and restarted; finished runs are skipped. If the CSV files are in another folder, pass `--data_dir PATH`.
